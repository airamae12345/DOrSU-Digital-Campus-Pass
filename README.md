# DOrSU Digital Campus Pass

## ITMSD1 - Laboratory Exercise 03
### React Native Fundamentals

A React Native mobile application developed for the ITMSD 1 Laboratory Exercise 03. The application demonstrates React Native fundamentals through a digital student campus pass for Davao Oriental State University (DOrSU).

## Features

- Student digital identification card
- Student profile information
- Active and suspended pass status
- Gate scan counter
- Scan counter reset
- Dynamic state management using `useState`
- Reusable `StudentCard` component
- Reusable `ScanCounter` component
- TypeScript props
- Flexbox layout
- React Native `StyleSheet`
- Peer Props demonstration

## Technologies Used

- React Native
- Expo
- TypeScript
- React Hooks
- `useState`
- React Native StyleSheet
- Flexbox
